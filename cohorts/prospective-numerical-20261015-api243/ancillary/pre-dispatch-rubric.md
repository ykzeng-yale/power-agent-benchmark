# Separate prospective scientific audit rubric

Apply after capture to the actual executed code/stdout and final response. This
rubric adds no instructions to the frozen 12 requests and supplies no reference
value to the model. It does not replace or retrospectively alter the primary
scalar composite. Record pass, demonstrated failure, qualified/unresolved, or
not requested for each applicable item. Keep specific unsuccessful attempts.

For all 12 questions, check the actual method, hypothesis, outcome scale, inputs,
count units and rounding against the unchanged query. Verify code follows the
stated prospective test rather than an observed test or a different convention.
Inspect integer boundary/predecessor evidence where available; scalar reference
agreement alone does not prove that code implements a general valid solver.
Check for unreported method substitution or assumptions that change the target.

For the three prediction-development questions, confirm that the actual executed
code uses the specifically requested pmsampsize version 1.1.3 and the correct
binary, continuous or survival family. Retain session/package version evidence;
an unsupported package-use claim is not certified by a matching scalar. Check
candidate parameter count, transformations if specified, outcome prevalence or
rate/horizon, anticipated R-squared scale, shrinkage and all requested defaults.
Check all returned criteria, their binding maximum, expected events or person
time, and per-parameter units where reported. Distinguish a placeholder maximum
printed by a package from a separately demonstrated precision minimum.

For survival risk precision, recompute the two transformed confidence limits at
the returned sample size and compare each margin to the specified absolute risk
precision. If a supplementary minimum is claimed, check both margins and its
integer predecessor. Do not certify a one-sided transformed-margin calculation
as a two-bound minimum. The frozen primary expected sample size remains the
specified package/default calculation; supplementary failures are reported
explicitly and separately rather than hidden by its correct value.

Check prose for attribution of user inputs, stated assumptions, analytic versus
simulation status, scope of source reading, and limitations. Prediction tier
does not require Monte Carlo by itself. No task in this cohort requests a plot
or mandatory document acquisition, so neither is added as a success criterion.

Auditors may see method families and frozen references, so this is a transparent
source-bound scientific audit, not a blinded human reliability study. Report
actual read/execution scope and unresolved ancillary claims without converting
them into a universal scientific-validity certificate.
