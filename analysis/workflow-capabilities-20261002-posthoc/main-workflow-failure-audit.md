## Measurement contracts that require qualification

Three actual task/runtime–scorer mismatches must be retained beside original strict results and any separately labeled posthoc sensitivity analysis. They are not reasons to rewrite frozen outcomes.

1. **Unrequested figure basename.** Every dispatched calculation query asks for an actual PNG/PDF sensitivity plot and fixes only `sensitivity.csv`, metric names and CSV columns. None specifies `sensitivity.png` or `sensitivity.pdf`; request common fields only set verification/budgets/source access. The frozen scorer nevertheless recognizes only those two image names. Actual delivered `sensitivity_plot.png` files are therefore classified missing_sensitivity_figure. Filename failure is not proof of missing plots, correct plots or correct companion data.
2. **Exact numeric representation.** Runtime grounding uses exact metric/unit strings and relative numeric tolerance1e-9. Scorer linkage uses Python exact equality on all three fields. Completed binary-Cox single sharedr2 differs by9.95e-14 in a continuous-event row and is rejected on linkage. This is not an observed substantive scientific error.
3. **All review IDs must have JSON.** The runtime permits successful current-round nonJSON/file-check reviewer IDs alongside at least one actual JSON numerical reviewer. The scorer filters every cited reviewer ID to computed-object evidence. Eight completed pass-review records are penalized for including successful nonJSON checks alongside real numerical checks. Actual stale/wrong-role/failed evidence and missing numerical checks remain genuine failures.

The source score is also a conjunction with a narrow meaning: the named document must be found by search, then read, hashed and cited. A successful direct named-document read/citation does not suffice, and a broader method search returning a combined manual does not match the named function-document URL. Thus source_conjunction_pass0/0/0/1 must not be described as provider failure or absent primary-document acquisition. Named document reads and final citations are counted separately in JSON. The exact original source criterion remains unchanged.

## Fair interpretation and current limits

The study uses two repeated calls for eight selected tasks, with matched explicit operation profiles and required verification. It separates shared-author conversation from fresh blind precheck/review, but not independent models, independent numerical libraries or equal realized costs. Source caches, token volume and time differ. Repeated methods and small family count preclude general superiority claims.

Main attempts receive fresh question-only CLI payloads; they do not contain the browser's restored prior chat. No conclusion about conversational contamination follows from this cohort or the separate browser failure.

Real scientific failures remain after interface/specification issues are separated: three final candidates disagree numerically with the frozen oracle, many outputs are missing or ungrounded, complex formulas can be wrong, and blind reviewers may not obtain a valid quantitative check. A completed model critique is not an oracle. Figure hashes/headers, correct CSV rows and role handoff are not automatic scientific figure certificates; the frozen visual rubric must be reported separately.

Preserve all64raw/transports and original criteria. Any contract-aligned rescoring belongs to a separately versioned posthoc diagnostic with original strict results still visible; it must not mask mathematical errors, failed/uncited/stale evidence, missing requested data or failed workflows.
