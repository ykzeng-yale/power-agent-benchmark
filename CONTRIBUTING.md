# Scientific benchmark contributions

Each new task requires an answer-free prompt and response schema, explicit estimand/test/design and sample-size unit, source URL with verified chapter/example locator, and a provenance class: published worked example, official primary-method illustration, or newly constructed task. A package call or synthetic variant must not be described as a textbook answer. Record source rounding and errata separately.

Write independently specified R and numerical references; compare results and retain environment/version information. Invert integer allocation grids and freeze tolerances before model runs. Monte Carlo tasks additionally require a fixed DGP/test, trials, seeds, all-trials failure denominator, MCSE and interval. Avoid guessed ranges and mixing different test procedures.

Group all variants and related questions by source family. Freeze development/evaluation splits, answers, scorer, protocol and harness before calls. Keep reference answers/code outside agent requests. Current public examples are developer-exposed, so a split alone does not make an unseen holdout.

Any post-freeze correction creates a new suite version or separately labelled cohort. Preserve original failures; do not rerun only failed attempts, exclude provider errors or relax thresholds after observing results. The main scorer is judge-free and requires structured executed evidence. See [audited protocol](docs/audited-methodology.md).
